About This App

This app is a simple flash card application built with Angular. It allows users to create, view, and manage flash cards for studying purposes.

The app is designed to be user-friendly and responsive, making it accessible on various devices.

Features include:

  • Create and manage flash cards
  • View and study flash cards
  • Favourite questions based on user interactions
  • Search flash cards based on flash card content

Technologies Used:

  • Angular
  • TypeScript
