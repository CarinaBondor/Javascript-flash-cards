About This App

This app is a simple flash card application built with Angular. It allows users to view and manage flash cards for studying purposes.

Features include:

  • View and study flash cards
  • Favourite questions based on user interactions
  • Search flash cards based on flash card content

Plans for the future of this project

  • Add functionality to create flash cards
  • Add multiple topics for the flashcards
  • Add quizzes

Technologies Used:

  • Angular
  • TypeScript
  • Angular Material
